Do the alphabets agree on BCL2?

You expected this: if Ced9's BH1 stretch is like BCL2's, several alphabets should each find a region there, and that agreement should push BCL2 up the list. This page uses the real regions from notebook 241's searches of Ced9 and P66 against the GENCODE v49 canonical human proteins, all 19 alphabets. Change how agreement is counted below and see where BCL2 lands.

Short answer:

Rank BCL2 yourself

A spot joins regions from different alphabets that sit on the same diagonal of the same human protein (the two stretches are in register, so target start minus query start is equal) and overlap on the query. For each human protein the page takes its spot with the most agreement, then counts how many proteins beat the true partner.

Query and its true partner

Changes which search is counted.

E-value cut:

An alphabet counts at a spot only if its own region there has an E-value below the cut. The E-value is how many regions this good one search of the human proteome gives by chance. Spots are rebuilt from the regions that pass.

Why agreement does not help here

  
    
    
  1. An identical stretch is a match in every alphabet. Grouping residues into classes never splits two identical residues, so every alphabet whose k-mers fit inside an identical stretch reports it. That is why  The alphabets are not voting independently; they all see the same identical letters. Figure 4 shows this over every spot.
    2. 
    
  2. The alphabets mostly split residues the same way. Almost every alphabet keeps hydrophobic residues apart from charged ones (hover the alphabet names above). So a chance stretch that looks alike in one alphabet looks alike in most of them. Notebook 242 (PR 48) measured how far the alphabets are from independent.
    3. 
    
  3. BCL2's BH1 is seen only by coarse alphabets, and three of its four are one alphabet. 
    4. 
    
  4. No alphabet calls BCL2's BH1 below E = 10. 
    5.
