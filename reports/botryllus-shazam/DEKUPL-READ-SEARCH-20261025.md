# DE-kupl reads, extensions and external searches

Select every canonical DNA 31-mer with finite, global BH-adjusted P strictly below 0.05 from the three completed genotype/collection-blocked DE-kupl contrasts. Preserve contrast, adjusted P and effect per seed; deduplicate only identical canonical sequences, never select a top-N subset.

Scan the same 64 validated trimmed paired-read libraries used for counting. A Rust rolling 31-mer lookup matches both strands, resets at ambiguous bases, and retains each supporting pair once, including its unmatching mate. Per-library FASTQ.gz files preserve original read headers. Per-library hits.tsv.gz records query ID, read ID, mate, zero-based position and strand. The library identity is in the filename and manifest. These are trimmed reads, not newly assembled transcripts or the untouched archive FASTQ.

Run Compactors 2.11.9 on recruited reads with both seed orientations and all anchor occurrences. Preserve branch rows, source seeds and direct 31-mer queries with no extension. Compactors defaults limit branches to 1000 compactors per anchor and 20 child compactors per step; this is candidate extension, not an exhaustive isoform reconstruction. Extension supports are pooled across libraries; individual read mappings remain available per library.

Search DNA seeds and extensions against the four prepared external tunicate runs at scaled 10/100. The complete 5776-run inventory is not yet a completed searchable collection. Translate stop-free stretches in all six frames; Branchwater manysketch sketches fragments, and MinHash unions group their hashes back under their source DNA query. Fragment records are not independent biological queries. Swiss-Prot is searched at scaled 5; translated SRA targets at scaled 10/100. Settings stay DNA k31, protein k7, Dayhoff k12 and HP k30. A bare 31-mer cannot supply Dayhoff/HP k-mers at those lengths. Missing hashes are unsearchable, not biological absence.

Use Branchwater 0.9.15 manysketch and manysearch with Sourmash 4.9.4. Reuse validated target signature ZIPs in streaming searches. Explicit -t 0 -A requests any nonzero overlap; raw candidates do not establish homology, function or condition-specific expression. Record versions, source/model/output hashes, query coverage per alphabet/scale and GNU time measurements per command. Source read recruitment has separate per-library timings. No ordinary Python search loop is used for retrieval.

Runtime guard: the resumed trimming job runs a known-answer read-pair/Compactors/Branchwater test and a tiny nf-core fixture before experimental trimming. Local regressions check the adjusted-P boundary, reverse-complement canonicalization, ambiguous-base resets and duplicated tool options. Full DE-kupl read-search is dependent on completed abundance tests and successful tool checks. Initial allocation: 16 CPUs, 96 GB, 48 h; four concurrent read scanners and a 24 GB Compactors read buffer. Full-scale runtime is not measured; this is a resource model, not an ETA.
